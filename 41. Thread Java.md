# Thread trong Java
## 1. Giới thiệu về Thread trong Java
Thread (luồng) trong Java là một đơn vị thực thi nhỏ nhất của một chương trình. Mỗi chương trình Java có thể chứa nhiều thread, và mỗi thread có thể thực hiện các tác vụ riêng biệt đồng thời với các thread khác. Điều này giúp tận dụng tối đa tài nguyên hệ thống và cải thiện hiệu suất của ứng dụng.

### 1.1. Tại sao sử dụng Thread?
- **Đa nhiệm (Multitasking)**: Cho phép thực hiện nhiều tác vụ cùng một lúc.
- **Cải thiện hiệu suất**: Tận dụng tốt hơn tài nguyên CPU và giảm thời gian chờ.
- **Giao diện người dùng mượt mà**: Giúp giao diện người dùng không bị đóng băng khi thực hiện các tác vụ nặng.
- **Xử lý song song**: Thực hiện các tác vụ độc lập cùng lúc.
### 1.2. Các trạng thái của Thread
Một thread trong Java có thể ở trong một trong các trạng thái sau:
- **New**: Thread mới được tạo nhưng chưa bắt đầu.
- **Runnable**: Thread đang sẵn sàng để chạy.
- **Blocked**: Thread bị chặn và không thể tiếp tục thực thi.
- **Waiting**: Thread đang chờ một sự kiện hoặc tín hiệu.
- **Timed Waiting**: Thread đang chờ trong một khoảng thời gian xác định.
- **Terminated**: Thread đã hoàn thành công việc và kết thúc.
## 2. Tạo và quản lý Thread trong Java
### 2.1. Cách tạo Thread
#### 2.1.1 Sử dụng lớp Thread và giao diện Runnable
Có hai cách chính để tạo một thread trong Java:
- **Kế thừa lớp Thread**: Tạo một lớp con của lớp Thread và ghi đè phương thức run().
```java
class MyThread extends Thread {
    public void run() {
        System.out.println("Thread is running");
    }
}
public class Main {
    public static void main(String[] args) {
        MyThread thread = new MyThread();
        thread.start(); // Bắt đầu thread
    }
}
```
- **Cài đặt giao diện Runnable**: Tạo một lớp triển khai giao diện Runnable và định nghĩa phương thức run().
```java
class MyRunnable implements Runnable {
    public void run() {
        System.out.println("Thread is running");
    }
}
public class Main {
    public static void main(String[] args) {
        Thread thread = new Thread(new MyRunnable());
        thread.start(); // Bắt đầu thread
    }
}
```
#### 2.1.2 Sử dụng Lambda Expression (Java 8 trở lên)
```java
public class Task {

    private static final Logger log = LoggerFactory.getLogger(Task.class);

    public static void ioIntensive(int i){

        try {
            log.info("starting I/O task {}. Thread Info: {}", i, Thread.currentThread());
            Thread.sleep(Duration.ofSeconds(10));
            log.info("ending I/O task {}. Thread Info: {}", i, Thread.currentThread());
        } catch (InterruptedException e) {
            throw new RuntimeException(e);
        }

    }

}
```
> Sử dụng Lambda Expression để tạo thread một cách ngắn gọn.
```java
private static final int MAX_PLATFORM = 10_000;
public static void main(String[] args) {

    for (int i = 0; i < MAX_PLATFORM; i++) {
        final int taskId = i;
        Thread thread = new Thread(() -> Task.ioIntensive(taskId));
        thread.start();
    }

}
```
> Sử dụng Thread.Builder (Java 19 trở lên) để tạo thread với các tùy chọn cấu hình.
```java
public static void main(String[] args) {
    var builder = Thread.ofPlatform().name("task-", 1); // Tạo builder với tên tiền tố "task-" và số thứ tự bắt đầu từ 1
    for (int i = 0; i < MAX_PLATFORM; i++) {
        final int taskId = i;
        Thread thread = builder.unstarted(() -> Task.ioIntensive(taskId)); // Tạo thread chưa khởi động với công việc I/O
        thread.start(); // Bắt đầu thread
    }

}
```

### 2.2. Quản lý Thread
Java cung cấp nhiều phương thức để quản lý thread, bao gồm:
- **start()**: Bắt đầu thực thi thread.
- **sleep(long millis)**: Tạm dừng thread trong một khoảng thời gian xác định.
- **join()**: Chờ một thread hoàn thành trước khi tiếp tục.
- **interrupt()**: Gửi tín hiệu ngắt đến một thread.
## 3. Đồng bộ hóa Thread trong Java
Khi nhiều thread truy cập cùng một tài nguyên chung, có thể xảy ra tình trạng tranh chấp dữ liệu. Để tránh điều này, Java cung cấp cơ chế đồng bộ hóa (synchronization).
### 3.1. Từ khóa synchronized
Từ khóa synchronized được sử dụng để đảm bảo rằng chỉ một thread có thể truy cập vào một phương thức hoặc khối mã tại một thời điểm.
```java
class Counter {
    private int count = 0;

    public synchronized void increment() {
        count++;
    }

    public int getCount() {
        return count;
    }
}
```
### 3.2. Khối synchronized
Bạn cũng có thể sử dụng khối synchronized để đồng bộ hóa một phần cụ thể của mã.
```java
public void increment() {
    synchronized(this) {
        count++;
    }
}
```
### 3.3. Sử dụng Lock
Java cung cấp lớp Lock trong gói java.util.concurrent.locks để cung cấp cơ chế đồng bộ hóa linh hoạt hơn.
```java
import java.util.concurrent.locks.Lock;
import java.util.concurrent.locks.ReentrantLock;
class Counter {
    private int count = 0;
    private final Lock lock = new ReentrantLock();

    public void increment() {
        lock.lock();
        try {
            count++;
        } finally {
            lock.unlock();
        }
    }

    public int getCount() {
        return count;
    }
}
```
## 4. CoundownLatch và CyclicBarrier
Java cung cấp các công cụ trong gói java.util.concurrent để quản lý sự đồng bộ giữa các thread, bao gồm CountDownLatch và CyclicBarrier.
### 4.1. CountDownLatch
CountDownLatch cho phép một hoặc nhiều thread chờ cho đến khi một số lượng thread khác hoàn thành công việc của chúng.
```java
import java.util.concurrent.CountDownLatch;
class Main {
    public static void main(String[] args) throws InterruptedException {
        CountDownLatch latch = new CountDownLatch(3); // Chờ 3 thread hoàn thành

        Runnable task = () -> {
            System.out.println("Task started");
            try { 
                Thread.sleep(1000); // Simulate work
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            System.out.println("Task completed");
            latch.countDown(); // Giảm số đếm của latch khi hoàn thành 1 task
        };

        new Thread(task).start();
        new Thread(task).start();
        new Thread(task).start();

        latch.await(); // Đợi cho đến khi tất cả các thread hoàn thành
        System.out.println("All tasks completed");
    }
}
```

### 4.2. CyclicBarrier
CyclicBarrier cho phép một nhóm thread chờ nhau tại một điểm cụ thể trước khi tiếp tục thực thi.
```java
import java.util.concurrent.BrokenBarrierException;
import java.util.concurrent.CyclicBarrier;
class Main {
    public static void main(String[] args) {
        CyclicBarrier barrier = new CyclicBarrier(3, () -> {
            System.out.println("All parties have arrived at the barrier, let's proceed!");
        });

        Runnable task = () -> {
            System.out.println("Task started"); 
            try { 
                Thread.sleep(1000); // Simulate work
                System.out.println("Task waiting at barrier");
                barrier.await(); // Chờ tại barrier
            } catch (InterruptedException | BrokenBarrierException e) {
                e.printStackTrace();
            }
            System.out.println("Task completed");
        };

        new Thread(task).start();
        new Thread(task).start();
        new Thread(task).start();
    }
}
```

# Daemon Thread trong Java
Daemon Thread là một loại thread đặc biệt trong Java, được thiết kế để chạy nền và hỗ trợ các thread khác trong quá trình thực thi của ứng dụng. Khi tất cả các thread không phải daemon (user thread) kết thúc, JVM sẽ tự động kết thúc tất cả các daemon thread và dừng chương trình.

## 1. Đặc điểm của Daemon Thread
- **Chạy nền**: Daemon thread thường được sử dụng để thực hiện các tác vụ nền như thu gom rác (Garbage Collection), giám sát hệ thống, hoặc các dịch vụ hỗ trợ khác.
- **Không ngăn JVM kết thúc**: Khi tất cả các user thread kết thúc, JVM sẽ tự động kết thúc tất cả các daemon thread.
- **Không thể sử dụng để thực hiện các tác vụ quan trọng**: Vì daemon thread có thể bị kết thúc bất cứ lúc nào khi không còn user thread, nên không nên sử dụng chúng để thực hiện các tác vụ quan trọng.
## 2. Tạo Daemon Thread
Kết hợp với `CountDownLatch` để hiển thị cách tạo và sử dụng daemon thread trong Java.
```java
public static void main(String[] args) throws InterruptedException {
    CountDownLatch latch = new CountDownLatch(MAX_PLATFORM); // Tạo CountDownLatch với số đếm ban đầu

    var builder = Thread.ofPlatform().daemon().name("daemon-task-", 1); // Tạo builder cho daemon thread với tên tiền tố "daemon-task-"
    for (int i = 0; i < MAX_PLATFORM; i++) {
        final int taskId = i;
        Thread thread = builder.unstarted(() -> {
            Task.ioIntensive(taskId); // Thực hiện công việc I/O
            latch.countDown(); // Giảm số đếm của latch khi hoàn thành task
        });
        thread.start(); // Bắt đầu daemon thread
    }
    latch.await(); // Đợi cho đến khi tất cả các daemon thread hoàn thành
}
```
Trong ví dụ trên, chúng ta tạo một số lượng lớn daemon thread để thực hiện các tác vụ I/O. Sử dụng `CountDownLatch` để đảm bảo rằng chương trình chính sẽ chờ cho đến khi tất cả các daemon thread hoàn thành công việc của chúng trước khi kết thúc.

# Virtual Thread trong Java
Virtual Thread là một tính năng mới được giới thiệu trong Java 19 như một phần của Project Loom. Virtual Thread cung cấp một cách tiếp cận nhẹ hơn và hiệu quả hơn để xử lý đa luồng so với các thread truyền thống (platform thread). Chúng được thiết kế để hỗ trợ hàng triệu luồng đồng thời mà không gây áp lực lớn lên hệ thống.
## 1. Đặc điểm của Virtual Thread
- **Nhẹ hơn**: Virtual Thread sử dụng ít tài nguyên hệ thống hơn so với platform thread, cho phép tạo và quản lý hàng triệu luồng đồng thời.
- **Quản lý bởi JVM**: Virtual Thread được quản lý bởi JVM thay vì hệ điều hành, giúp giảm thiểu overhead liên quan đến việc chuyển đổi ngữ cảnh (context switching).
- **Tương thích với API hiện có**: Virtual Thread có thể sử dụng cùng các API đồng bộ hóa và các thư viện hiện có mà không cần thay đổi mã nguồn.

## 2. So sánh Virtual Thread và Deamon Thread
| Đặc điểm               | Virtual Thread                          | Daemon Thread                           |
|-----------------------|----------------------------------------|----------------------------------------|
| Mục đích sử dụng      | Xử lý đa luồng nhẹ và hiệu quả         | Chạy nền để hỗ trợ các thread khác     |
| Quản lý                | Bởi JVM                                | Bởi hệ điều hành                       |
| Tài nguyên sử dụng    | Ít tài nguyên hơn, hỗ trợ hàng triệu luồng | Sử dụng tài nguyên hệ thống như platform thread |
| Kết thúc               | Kết thúc khi tất cả các user thread kết thúc | Kết thúc khi tất cả các user thread kết thúc |

> Giả sử, Máy ảo có xCPU (Xử lý tối đa x luồng đồng thời), `xCPU = Runtime.getRuntime().availableProcessors();`
> - Nếu thực hiện `N` tác vụ, mỗi tác vụ có thời gian chờ I/O là `1s`, nếu `N <= xCPU` thì Platform Thread xử lý trong `1s`. `N >> xCPU`, Platform Thread sẽ mất `ceil(N/xCPU)` do mỗi 1 task phải chờ I/O (thực hiện được 1 khoảng thời gian sẽ phải nhường CPU cho task khác, tổng thời gian chờ sẽ là `ceil(N/xCPU) * 1s`).
> - Với Virtual Thread, do nhẹ hơn rất nhiều, có thể tạo `N` Virtual Thread để xử lý `N` tác vụ đồng thời, tổng thời gian sẽ là `1s`, bất kể `N` lớn đến đâu. Bởi vì Virtual Thread không bị giới hạn bởi số lượng CPU, chúng có thể chờ I/O mà không chiếm dụng tài nguyên CPU, mặc định JVM có thể tạo hàng triệu Virtual Thread, nhưng CPU sẽ vẫn chỉ hiểu đang thực hiện 1 task tại 1 thời điểm, trong khi 1 task đó đang có nhiều Virtual Thread.
## 3. Tạo và sử dụng Virtual Thread
Dưới đây là ví dụ về cách tạo và sử dụng Virtual Thread trong Java:
```java
public static void main(String[] args) throws InterruptedException {
    CountDownLatch latch = new CountDownLatch(MAX_VIRTUAL); // Tạo CountDownLatch với số đếm ban đầu

    var builder = Thread.ofVirtual().name("virtual-task-", 1); // Tạo builder cho virtual thread với tên tiền tố "virtual-task-"
    for (int i = 0; i < MAX_VIRTUAL; i++) {
        final int taskId = i;
        Thread thread = builder.unstarted(() -> {
            Task.ioIntensive(taskId); // Thực hiện công việc I/O
            latch.countDown(); // Giảm số đếm của latch khi hoàn thành task
        });
        thread.start(); // Bắt đầu virtual thread
    }
    latch.await(); // Đợi cho đến khi tất cả các virtual thread hoàn thành
}
```
Trong ví dụ trên, chúng ta tạo một số lượng lớn virtual thread để thực hiện các tác vụ I/O. Sử dụng `CountDownLatch` để đảm bảo rằng chương trình chính sẽ chờ cho đến khi tất cả các virtual thread hoàn thành công việc của chúng trước khi kết thúc.

## 4. Khi nào nên sử dụng Virtual Thread
Virtual Thread rất phù hợp cho các ứng dụng cần xử lý nhiều kết nối đồng thời, chẳng hạn như các ứng dụng web, dịch vụ mạng, hoặc các hệ thống xử lý sự kiện. Chúng giúp giảm thiểu overhead và cải thiện hiệu suất mà không cần phải thay đổi nhiều mã nguồn hiện có.

## 5. Vấn đề Pinning Threads
Khi sử dụng Virtual Thread, có thể gặp phải vấn đề "pinning threads" khi một Virtual Thread bị khóa vào một Platform Thread trong thời gian dài, điều này có thể làm giảm hiệu suất của hệ thống. Để tránh vấn đề này, nên sử dụng các API không chặn (non-blocking) và các thư viện hỗ trợ Virtual Thread.
Có thể lấy ví dụ về việc sử dụng từ khóa `synchronized` trong Virtual Thread:
```java
class Counter {
    private int count = 0;

    public synchronized void increment() {
        count++;
    }

    public int getCount() {
        return count;
    }
}

public static void main(String[] args) throws InterruptedException {
    CountDownLatch latch = new CountDownLatch(MAX_VIRTUAL); // Tạo CountDownLatch với số đếm ban đầu

    var builder = Thread.ofVirtual().name("virtual-task-", 1); // Tạo builder cho virtual thread với tên tiền tố "virtual-task-"
    Counter counter = new Counter(); // Tạo một đối tượng Counter để chia sẻ giữa các virtual thread
    for (int i = 0; i < MAX_VIRTUAL; i++) {
        final int taskId = i;
        Thread thread = builder.unstarted(() -> {
            counter.increment(); // Tăng biến đếm trong Counter
            latch.countDown(); // Giảm số đếm của latch khi hoàn thành task
        });
        thread.start(); // Bắt đầu virtual thread
    }
    latch.await(); // Đợi cho đến khi tất cả các virtual thread hoàn thành
    System.out.println("Final count: " + counter.getCount()); // In ra giá trị cuối cùng của biến đếm
}
```
Trong ví dụ trên, nếu một Virtual Thread gọi phương thức `increment()` và bị chặn bởi một Virtual Thread khác đang giữ khóa, thì Virtual Thread đầu tiên sẽ bị "pinned" vào một Platform Thread trong thời gian chờ. Điều này có thể làm giảm hiệu suất của hệ thống nếu có nhiều Virtual Thread bị chặn như vậy.

### 5.1. Giải pháp tránh Pinning Threads
- Sử dụng `Java 25` trở lên, nơi đã cải tiến cơ chế đồng bộ hóa để giảm thiểu vấn đề pinning threads.
- Sử dụng `ReentrantLock` thay vì từ khóa `synchronized` để có kiểm soát tốt hơn về việc quản lý khóa.
```java
import java.util.concurrent.locks.Lock;
import java.util.concurrent.locks.ReentrantLock;
class Counter {
    private int count = 0;
    private final Lock lock = new ReentrantLock(); // Sử dụng ReentrantLock để quản lý đồng bộ hóa 

    public void increment() {
        lock.lock(); // Khóa trước khi tăng biến đếm
        try {
            count++; // Tăng biến đếm
        } finally {
            lock.unlock(); // Mở khóa sau khi hoàn thành
        }
    }

    public int getCount() {
        return count;
    }
}

public static void main(String[] args) throws InterruptedException {
    CountDownLatch latch = new CountDownLatch(MAX_VIRTUAL); // Tạo CountDownLatch với số đếm ban đầu

    var builder = Thread.ofVirtual().name("virtual-task-", 1); // Tạo builder cho virtual thread với tên tiền tố "virtual-task-"
    Counter counter = new Counter(); // Tạo một đối tượng Counter để chia sẻ giữa các virtual thread
    for (int i = 0; i < MAX_VIRTUAL; i++) {
        final int taskId = i;
        Thread thread = builder.unstarted(() -> {
            counter.increment(); // Tăng biến đếm trong Counter
            latch.countDown(); // Giảm số đếm của latch khi hoàn thành task
        });
        thread.start(); // Bắt đầu virtual thread
    }
    latch.await(); // Đợi cho đến khi tất cả các virtual thread hoàn thành
    System.out.println("Final count: " + counter.getCount()); // In ra giá trị cuối cùng của biến đếm
}
```
Trong ví dụ trên, việc sử dụng `ReentrantLock` giúp giảm thiểu nguy cơ pinning threads so với việc sử dụng từ khóa `synchronized`, đặc biệt khi chạy trên Virtual Thread.
## 5.1. ThreadFactory cho Virtual Thread
Khi sử dụng Virtual Thread trong các ứng dụng phức tạp, việc quản lý việc tạo và cấu hình các Virtual Thread có thể trở nên khó khăn. Để giải quyết vấn đề này, Java cung cấp một cách tiếp cận thông qua việc sử dụng `ThreadFactory`.

`ThreadFactory` là một giao diện trong Java cho phép bạn tùy chỉnh cách các thread được tạo ra. Bằng cách sử dụng `ThreadFactory`, bạn có thể kiểm soát các thuộc tính của Virtual Thread như tên, mức độ ưu tiên, và các đặc tính khác một cách dễ dàng hơn. Ngoài ra, việc sử dụng `ThreadFactory` giúp mã nguồn trở nên sạch sẽ và dễ bảo trì hơn, đặc biệt khi bạn cần tạo nhiều Virtual Thread với các cấu hình khác nhau trong cùng một ứng dụng.

Dưới đây là ví dụ về cách sử dụng `ThreadFactory` để tạo Virtual Thread trong Java:
```java
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.ThreadFactory;
public class VirtualThreadFactoryExample {
    private static final int MAX_VIRTUAL = 1000; // Số lượng Virtual Thread cần tạo

    public static void main(String[] args) throws InterruptedException {
        CountDownLatch latch = new CountDownLatch(MAX_VIRTUAL); // Tạo CountDownLatch với số đếm ban đầu

        // Tạo ThreadFactory cho Virtual Thread
        ThreadFactory virtualThreadFactory = Thread.ofVirtual().name("virtual-task-", 1).factory();

        for (int i = 0; i < MAX_VIRTUAL; i++) {
            final int taskId = i;
            // Sử dụng ThreadFactory để tạo Virtual Thread
            Thread thread = virtualThreadFactory.newThread(() -> {
                Task.ioIntensive(taskId); // Thực hiện công việc I/O
                latch.countDown(); // Giảm số đếm của latch khi hoàn thành task
            }); // Khởi tạo Virtual Thread không khởi động
            thread.start(); // Bắt đầu virtual thread
        }
        latch.await(); // Đợi cho đến khi tất cả các virtual thread hoàn thành
    }
}
```
